# Zombie Arena

Zombie Arena is a top-down, close-quarters survival shooter. The player is armed with a gun and must fend off waves of zombies that spawn into the arena.

## Gameplay

- Shoot and survive against waves of zombies.
- The number of zombies spawned increases with each wave.
- The arena size changes as the player progresses through waves, keeping the action fresh and increasingly challenging.

## Built With

- **C++**
- **[SFML](https://www.sfml-dev.org/)** (Simple and Fast Multimedia Library) — used for rendering, input handling, and game loop management.

## Building the Project

1. Install [SFML](https://www.sfml-dev.org/download.php) (ensure the version matches your compiler).
2. Open the project solution in Visual Studio.
3. Make sure SFML include/lib paths are configured in the project properties.
4. Build and run (`Ctrl+F5` or `F5` to debug).

## Controls

- **Mouse** — Aim
- **Left Click** — Shoot
- **WASD / Arrow Keys** — Move
